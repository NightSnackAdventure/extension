Fork of RealTools browser extension for Chrome and Firefox that currently shows GP values correctly and removes all horse image related features

disclaimer: i only tested this on Chrome and not Firefox because I made this for personal use and don't really care that much.

## Future updates

If a future HorseReality update breaks this, your best bet is updating it yourself instead of waiting for me to do it.

## How to use

Delete whichever manifest from the extensions directory that you don't need and name the remaining one `manifest.json`. Then figure out how to load extensions into your browser.
